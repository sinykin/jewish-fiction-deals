# Jewish Fiction Deals, 2000–2026

`MASTER_Jewish_Fiction_Deals_AllPresses_CONTENT.csv` lists 407 fiction book deals reported to Publishers Marketplace (2000–2026) whose deal announcements mention Jewish or Israeli content, across all presses.

## Columns

| Column | Description |
|---|---|
| Year | Year of the deal report |
| Deal date | Date the deal was reported |
| Title | Title as announced (`untitled` where none was given) |
| Author | Author(s) |
| Publisher (best-effort) | Acquiring publisher/imprint, extracted from the announcement |
| Category | Publishers Marketplace fiction category |
| Content term(s) | Matched terms (e.g., Jewish, Jews, Israel, Israeli, Hebrew, Judaism) |
| Deal ID | Publishers Marketplace deal ID |
| Deal URL | Link to the deal record (subscription required) |
